# Loan Prediction Using Decision Trees and Random Forest

This project uses Decision Tree and Random Forest models on the loan dataset to classify whether a loan will be fully paid or not.

## Files
- `loan_data.csv`
- `Decision_Trees_and_Random_Forest_Project.ipynb`

## Libraries Used
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Steps
- Import libraries
- Upload and read the dataset
- Explore and visualize the data
- Convert categorical variables
- Split the data
- Train the models
- Make predictions
- Evaluate the results
